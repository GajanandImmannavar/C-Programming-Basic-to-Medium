# C Programming Roadmap — Basic to Medium in 3 Days

The goal is **not to master all of C in 3 days**. The goal is to become comfortable enough with C to start solving problems and move toward **DSA**.

## 🟢 Day 1 — C Fundamentals + Problem-Solving Basics

| #  | Topic             | Must Learn                                    |
| -- | ----------------- | --------------------------------------------- |
| 1  | Introduction to C | Compiler, program structure, `main()`         |
| 2  | Basic Syntax      | `#include`, statements, comments              |
| 3  | Output            | `printf()`                                    |
| 4  | Variables         | Declaration, initialization, assignment       |
| 5  | Data Types        | `int`, `float`, `double`, `char`              |
| 6  | Constants         | Literals, `const`, basic `#define`            |
| 7  | Input             | `scanf()` and format specifiers               |
| 8  | Operators         | Arithmetic, assignment, relational, logical   |
| 9  | Type Conversion   | Implicit & explicit casting                   |
| 10 | Conditions        | `if`, `else`, `else-if`, nested `if`          |
| 11 | `switch`          | Menu/fixed-choice problems                    |
| 12 | Loops             | `for`, `while`, `do-while`                    |
| 13 | Loop Control      | `break`, `continue`                           |
| 14 | Number Problems   | Prime, palindrome, factorial, Fibonacci, etc. |

### Day 1 Practice

* Even/odd
* Positive/negative
* Largest of 2/3 numbers
* Calculator
* Factorial
* Prime number
* Reverse number
* Palindrome number
* Fibonacci
* GCD/LCM
* Sum/count of digits

### Day 2 Practice

**Arrays**

* Find maximum/minimum
* Second largest
* Reverse array
* Sum/average
* Linear search
* Count frequency
* Remove duplicates

**Strings**

* Find length
* Reverse string


## ⭐ Priority

If time becomes limited, follow this order:

```text
1. Variables & Data Types
2. Input/Output
3. Operators
4. if/else
5. Loops
6. Functions
7. Arrays
8. Strings
9. Pointers
10. Recursion
11. Structures
12. Dynamic Memory
```

### Don't spend these 3 days on:

* Advanced preprocessor techniques
* Function pointers
* Complex pointer expressions
* File handling
* Advanced memory management
* Unions/enums in depth
* Advanced macros

Those can come later.

**End goal:** after Day 3, you should be able to read and write normal C programs, solve beginner-to-medium programming problems, and have the foundation needed to start **DSA in C**.
