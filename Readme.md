# 🚀 C Programming — Basic to Medium

A structured **3-day C Programming learning journey** designed to build strong programming fundamentals, improve problem-solving skills, and create a foundation for **DSA in C**.

> 🎯 **Goal:** Not to master all of C in 3 days, but to become comfortable enough with C to write programs, solve beginner-to-medium problems, and start learning DSA.
